# Form seals

The Requisition and Issue Slip (FRM-ADM-SUP-011) prints a seal on each side of
the hospital name. Put clean, square PNGs here (transparent background, ~400px):

- `province-seal.png` — Province of Pangasinan seal (left)
- `hospital-seal.png` — Pangasinan Provincial Hospital seal (right)

If a file is missing, the letterhead prints without that seal.
